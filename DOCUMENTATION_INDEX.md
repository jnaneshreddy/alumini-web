### View the Dashboard
```bash
npm run dev
# Open http://localhost:3000/admin
```

### Build for Production
```bash
npm run build
npm run start
```

### Customize Colors
Edit `src/app/admin/admin.css` line 12:
```css
--accent-primary: #3b82f6;  /* Change to your color */
```
